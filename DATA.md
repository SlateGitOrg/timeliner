# Data

## Committed data

| path | what | size | source | license |
|---|---|---|---|---|
| `fixtures/incident/evidence/**` | synthetic Linux evidence tree for host `web01` (auth.log, syslog, cron.log, wtmp, btmp, utmp, journal export, bash/zsh/fish histories, dpkg.log, apt history.log, bodyfile, etc/hostname, etc/timezone, etc/localtime → generated TZif) | ≈ 740 KB | generated by `timeliner fixtures --out fixtures/incident` (seed 1, scale 1), see `src/fixtures.rs` | MIT (this repository) |
| `fixtures/incident/GROUND_TRUTH.json` | 22-step ground truth (UTC time, expected kind/user/fields/tag) | 7 KB | same generator | MIT |
| `fixtures/incident/STORY.md` | human-readable story table | 4 KB | same generator | MIT |
| `rules/default.yml` | default tagging rules | 6 KB | written for this project | MIT |

Everything is **synthetic**. No real host, person or incident is represented.
IP addresses come from the documentation and benchmark ranges (RFC 5737
`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24` and RFC 2544
`198.18.0.0/15`). Host names, accounts, SSH key fingerprints and journal
cursors are invented. The "payload" `/tmp/.x.sh` exists only as a bodyfile
line. No script content is shipped.

Regenerate with `make fixtures`. A test (`committed_fixture_is_reproducible_byte_for_byte`)
fails if the committed tree drifts from the generator.

## Data read at test time (optional)

`time::tzif::tests::reads_system_zoneinfo_when_available` reads
`/usr/share/zoneinfo/America/New_York` from the test machine, if present, to
cross-check the TZif reader against real IANA data. It is skipped when tzdata
is absent. Nothing is downloaded.

## Benchmark inputs

`timeliner bench` synthesizes its inputs in memory (`src/bench.rs`). Nothing
is written to disk or downloaded.
